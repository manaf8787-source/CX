# Audit report

Skill: `meo-admin-design-skill` · Reference: https://meo.framer.ai/ · Inspected: 2026-11-18 · Browser: desktop Chrome, 1912x948 viewport; tablet and phone via 1000px and 390px same-origin frames.

## Verdict

The visual system (colour, type, radii, shadows, spacing, component anatomy, motion timing, breakpoints) was extracted from live CSS and compiled motion configuration with high confidence. The main gaps are things the reference simply does not contain (semantic status colours, form states, focus styles, modals, disabled and loading states), which are supplied as clearly labelled derived specifications, and a few behaviours that could not be timed precisely.

## Missing from the reference (supplied as derived)

Semantic status colours beyond the four brand accents; error red; focus ring; pressed, disabled and loading states; text input, select, radio, switch and validation; modal, drawer, tooltip, popover, context menu; pagination, sorting, bulk actions, column controls; breadcrumbs; collapsed sidebar; notifications; command palette; empty, error and skeleton states; dense table row height and dense card metrics; reduced-motion handling; dark mode (not provided at all).

## Known deviations and cautions

1. `#767676` text fails AA on `#F2F2F2` and `#F6F6F6` (4.06 and 4.20). The reference uses it there; this skill instructs `#6E6E6E` on those surfaces.
2. The reference opens its dropdown on hover and auto-advances tabs. The admin guidance reverses both.
3. The reference fades the bottom of its table and animates decorative loops. Neither is appropriate for real data and both are excluded from the admin recipes.
4. Component measurements were taken at one desktop width. Fixed-size controls are reliable; fluid widths (cards, columns) are examples, not constants.
5. The site is a template and may change. Re-inspect before relying on a value that matters legally or commercially.
6. Screenshots are half-scale JPEGs intended as visual reference only.

## Recommendations for implementation

1. Start from `tokens/tokens.css` and `examples/meo-admin.css`; open `examples/admin-demo.html` to confirm the look in your environment before building further.
2. Build the sliding selection indicator and the label roll first: they carry most of the perceived quality.
3. Decide the density mode per page type early and encode it as a data attribute or context so cards, tables and controls switch together.
4. Add visual regression tests for shadows and radii; they are easy to flatten accidentally with resets or utility defaults.
5. Validate the derived status colours and focus ring with your accessibility reviewer; adjust the derived shades rather than the measured neutrals.
6. If a dark theme is required, design it deliberately (invert the two materials and rebuild shadow stacks); do not auto-invert these tokens.
7. To raise confidence on the low items above, record the site with DevTools Performance open and read the tab interval, ticker speed and per-word stagger directly.
